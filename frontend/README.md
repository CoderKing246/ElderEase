# ElderEase — Senior Assistance & Companionship Platform (v0.1.0 MVP Frontend)

ElderEase is a college Software Engineering project frontend built with **React**, **Vite**, **Tailwind CSS**, and **React Router**, designed to seamlessly integrate with an existing **Spring Boot 3.3.5 REST API** backend.

## Installation & Execution
```bash
npm install
npm run dev
```
